## What is Alpha Quest?

Alpha Quest is an educational adventure game for primary school children aged 6–11. Players become **Explorers** who travel through five subject worlds:

1. **Math World** — numbers, operations, geometry, measurement
2. **English Kingdom** — phonics, vocabulary, grammar, comprehension
3. **Science Lab** — living things, matter, forces, Earth, space
4. **Discovery World** — geography, history, cultures, landmarks
5. **Logic Temple** — patterns, memory, deduction, puzzles

Explorers complete missions, earn XP, unlock rewards, and build a personal world in the **Knowledge Builder**.
